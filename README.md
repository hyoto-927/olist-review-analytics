# Olist 리뷰 분석 | 판매자의 평점 방어와 기대매출 시나리오

**고객이 “아직 상품을 받지 못했다”고 남겼을 때, 판매자는 무엇부터 고쳐야 할까?** Team Frontier는 브라질 Olist의 주문·결제·리뷰를 연결해 불만의 종류, 이후 구매액, 평점 사이의 관계를 분석했다. 분석 결과를 판매자별 대응 우선순위와 Dify 챗봇의 답변 근거로 구성했다.

## 내가 맡은 Part 2 · 평점 방어와 기대매출

판매자에게 개선책을 제시하려면 어떤 불만이 중요한지와 함께, 그 문제를 줄였을 때 어느 정도의 거래액을 방어할 수 있는지도 설명해야 한다고 판단했다. 그래서 리뷰 이슈가 평점과 어떻게 연결되는지 분석하고, 평점과 주문 거래액(GMV)을 결합해 판매자가 대응 우선순위를 비교할 수 있는 두 가지 시나리오를 설계했다.

| 판매자가 내릴 결정 | 내가 설계한 계산 | 결과표에서 확인한 사례 |
| --- | --- | --- |
| **어떤 이슈에 먼저 대응할까?** (B안) | 주문별로 이슈 개선 전후의 저평점(3점 이하) 확률 차이에 해당 판매자의 거래액을 곱해 합산했다. | 배송 지연 이슈 입력값을 30% 줄이자 판매자 3,095명의 위험가중 거래액 합계가 **1,396,513 → 1,386,297헤알**로 변했다. 차이 **10,216헤알**은 이 가정에서 감소한 노출 규모다. |
| **평점 개선 목표를 어느 수준으로 잡을까?** (A안) | 같은 카테고리의 다음 평점 등급 평균 거래액을 현재 등급 평균과 비교하고, 그 배수를 판매자의 현재 거래액에 적용했다. | 다음 등급과 비교 가능한 2,839개 행 중 **1,511개(53.2%)**에서 다음 등급의 평균 거래액이 더 낮았다. 판매 규모나 상품 구성 차이도 함께 살펴야 목표로 쓸 수 있다. |

예를 들어 이미 거래된 100헤알 주문에서 모델의 저평점 확률이 40%에서 25%로 바뀌면 B안의 노출 감소분은 **15헤알**이다. 이 예시는 계산의 단위를 보여준다. 실제로 얼마의 매출을 지켰는지 확인하려면 배송 안내 개선 등을 시행하고, 비교 가능한 주문군에서 이후 구매·환불 금액을 측정해야 한다.

## 분석에서 나온 답

| 판매자의 질문 | 팀이 확인한 결과 | 활용 |
| --- | --- | --- |
| 어떤 불만부터 살펴볼까? | 미수령 리뷰는 선형모델에서 평점 **−0.63점**, 로지스틱 모델에서 저평점(3점 이하) 오즈 **3.76배**와 연관됐다. | 미수령 문의를 먼저 확인하고 배송 추적·응대 절차를 점검하는 근거 |
| 고객별 손실액을 얼마나 설명할까? | PCA 기반 변수 선택 후 Ridge의 손실 목표 R²는 180일 **0.054**, 365일 **−0.002**였다. | 개별 고객 손실액을 확정하기에는 설명력이 낮다. |
| 판매자에게 어떻게 전달할까? | 판매자별 이슈 요약표와 대응 지식 문서를 만들고, 발표에서 플랫폼 전체·판매자 개별 질문의 챗봇 화면을 시연했다. | 어떤 이슈와 지표를 근거로 대응을 제안했는지 확인 |

**오즈**는 사건이 일어날 확률을 일어나지 않을 확률로 나눈 값이다. 3.76배는 모델에서 추정한 오즈의 비율이다. 운영 개선 후의 평점 상승이나 매출 회복은 별도 실험이 필요하다.

## 리뷰 한 건이 판매자 진단으로 이어지는 과정

1. Olist 고객·주문·상품·판매자·결제 정보를 결합한다. 결제를 주문 단위로 합산하고 리뷰 ID 중복을 검사한다.
2. 포르투갈어 리뷰를 NLLB-200으로 영어로 번역하고 SiEBERT로 감성을 분석한다. 문장 단위 규칙으로 미수령, 지연, 파손, 환불 등 **14개 이슈**를 복수 표시한다.
3. 리뷰 시점 이후 180일·365일의 구매액을 계산한다. 부정 리뷰 노출과 미래 매출의 관계를 추정하고 판매자별 주요 이슈를 집계한다.
4. 평점 모델과 운영 변수로 점검할 항목을 고른다. 대응 문구와 측정 지표를 지식베이스로 묶어 챗봇이 참조하도록 구성한다.

두 산식은 원자료 없이도 실행할 수 있다. 아래 예제는 설명을 위해 새로 작성했다. B안에는 위의 100헤알 주문을, A안에는 현재 거래액 1,000헤알과 등급별 평균 500·600헤알을 입력해 각각 15헤알의 노출 감소분과 1,200헤알의 비교 시나리오를 계산한다.

```bash
python tools/scenarios.py
```

