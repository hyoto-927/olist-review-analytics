**Olist.** 발표자료가 설명하는 원천은 2016–2018년 브라질 전자상거래 공개 데이터로, 약 10만 건의 주문을 포함한다. 번역된 리뷰, 감성 분류, 규칙 기반 불만 라벨, 손실 추정치와 판매자 대응표는 분석으로 생성한 자료다. 사람이 판정한 불만 정답 또는 실제 손실 회계 기록과는 출처가 다르다.

**네이버.** 수집 노트북과 쇼핑 리뷰 병합 파일이 있고 Notion에는 가상 데이터 생성·가공 및 챗봇 작업이 기록돼 있다. 발표의 모델 성능표는 Olist 분석 맥락에서 제시됐다. 네이버에서 같은 성능이나 매출 효과가 검증됐다고 볼 자료는 확인하지 못했다.

**팀 기여.** 팀 발표에는 데이터 전처리·라벨링, SQL 통합, 텍스트 마이닝·감성 분석, 머신러닝, 챗봇 구현이 역할로 기록되어 있다. 포트폴리오 작성자는 Part 2의 평점 방어 및 기대매출 분석을 담당했다. 제출용 Part 2 노트북에서 이슈·평점 모델과 두 가지 거래액 시나리오의 계산식을 확인했다.

**공개 범위.** 새로 작성한 설명과 산식 예제, 결과표 조회 코드를 포함했다. 리뷰 원문, 고객·판매자 단위 데이터, Notion 원본, 발표 파일, 연결 정보는 원본 보관 위치에 둔다. 발표 마지막의 분석 시간 단축과 비용 절감은 기대 효과로 제시된 항목으로, 실측 성과를 산출할 비교 기록은 확인하지 못했다.
